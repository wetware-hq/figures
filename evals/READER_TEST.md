# Reader test (human tier)

Run when the chart's look or wording changes, not on every code change.
Each run needs a reader who has not seen that version. Log results next to the machine scores.

## Procedure (5 minutes per case)
1. Show the `test` copy of the case: the image with its gap and method wording, without answer-giving notes.
2. Ask the three questions below, in order, with no help.
3. Record the answers verbatim and mark each one pass or fail against the expected answers.
4. A case passes only if all three answers are correct. "Can't tell" is the correct answer wherever data is unobserved or not comparable.
5. Run once with a clinician and once with a lay reader. A lay-reader failure means the chart gets redrawn, not explained.

## The three questions
1. Which parts of this line were actually measured, and which weren't?
2. Did this result get better, worse, or can't you tell?
3. What do the words on the chart tell you?
